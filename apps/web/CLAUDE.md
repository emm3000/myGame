# apps/web

TanStack Start on Vite: the routes, the design system and the game screens. It reads the api through `@mygame/contracts` only.

## Commands

- `WEB_PORT=<port> API_PORT=<port> pnpm --filter @mygame/web dev` — dev server on `WEB_PORT`. The port has no default and `strictPort` is on: an unset or busy port fails instead of drifting. `/api/*` is proxied to the api on `API_PORT` with the `/api` prefix stripped, so the session cookie is same-origin.
- `pnpm --filter @mygame/web test` — Vitest in jsdom, `src/**/*.test.{ts,tsx}`; `vitest.setup.ts` runs Testing Library cleanup after each test.
- `pnpm --filter @mygame/web typecheck` — `tsc --noEmit`.
- `pnpm --filter @mygame/web drawables` — cuts every SVG under `public/art/places/` at levels 0 to 10 and converts `public/art/waste/` into their Android VectorDrawables in `apps/android/core/designsystem/src/main/res/drawable/` (`src/art/generateDrawables.ts`, through `tsx`). Run it after drawing or editing one of those SVGs; `src/art/townDrawables.test.ts` fails on a drift, a missing drawable or an orphan one.
- `pnpm --filter @mygame/web tokens` — writes `core:designsystem`'s `MyGameColors.kt`, `MyGameTypography.kt`, `MyGameTypeFamilies.kt`, `MyGameSpacing.kt`, `MyGameRadii.kt`, `MyGameSizes.kt`, `MyGameStrokeWidths.kt` and `MyGameTransitions.kt` in `apps/android/core/designsystem/src/main/kotlin/com/emm/mygame/core/designsystem/` from `src/design/tokens.ts` (`src/design/android/generateDesignSystem.ts`, through `tsx`). Run it after editing `tokens.ts`; `src/design/android/designSystemDriftsOf.test.ts` fails on a drifted value or a missing file.
- `pnpm --filter @mygame/web build` — production build through Nitro (`nitro()` from `nitro/vite`, after `tanstackStart()`, loaded for `build` and `vite preview` only: in `dev` its middleware runs before Vite's proxy and answers `/api/*` with the router's 404, #585): outside Vercel it writes `apps/web/.output/`; under `vercel build` it writes Vercel's Build Output to `.vercel/output/` at the repo root, the static files (`assets/` with hashed names, `art/` from `public/`) and one `__server` function (ADR 031). `WEB_PORT` and `API_PORT` are not read.
- `apps/web/vercel.json` — production on Vercel: `/api/:path*` rewritten to the api project's domain with the prefix stripped, so the session cookie stays same-origin as in `dev`; a one-year `immutable` `cache-control` on `/assets/` and a one-day one on `/art/` (unhashed, from `public/`); region `iad1`; Git deploys off, since `deploy.yml` deploys.

## Layout

- `src/routes/` — TanStack file routes. `__root.tsx` owns the document and the head, and links `src/styles.css`.
- `src/routeTree.gen.ts` — generated by the Start plugin on `dev` and `build`; committed so `typecheck` runs without a build, excluded from Biome. Never edit it by hand.
- `src/router.tsx` — `getRouter`, the entry Start looks for.
- `src/design/tokens.ts` — the look (ADR 043), the source of every value: the 20 colors with their light and dark values, the four `block-*`, `on-block` and `on-block-muted` one value in both themes; the one family `sans`, Schibsted Grotesk, loaded from Google Fonts by `__root.tsx` as `Schibsted+Grotesk:wght@400..800`, no italics; the 12 type styles of ADR 043's table (`word`, `display`, `numeral`, `reading`, `heading`, `button`, `title`, `gloss`, `body`, `label`, `caption`, `meta`; unitless line heights), where `word` carries a second size in `fontSizeFromMd` (44 px, 52 px from `md`), `numeral` alone carries `fontVariantNumeric: 'tabular-nums'` (a figure in `caption` takes `tabular-nums` on its own element, since `tnum` widens the punctuation of prose), and `meta`, the only uppercase style, carries `textTransform`; the spacing scale; the minimum heights `min-h-action` 60 px, `min-h-secondary` 52 px and `min-h-control` 48 px, and `w-control`, the `NoticeToggle`'s track; the sizes (`size-icon` 24 px, `size-icon-small` 20 px, `size-thumbnail` 96 px, `size-place-card` 160 px); the maximum widths (`max-w-form` 640 px, `max-w-reading` 65ch, under the theme's `extend`); `h-track`, 3 px; the radii (`rounded-sm` 8 px, `rounded-md` 16 px, `rounded-lg` 28 px, `rounded-pill`); no shadow, a `line` hairline in its place; the stroke widths (`hairline` 1, `control` 2, `icon` 2, which `IconFrame` reads, `mark` 2, `focus` 3; no Tailwind utility); the durations and easings, and `transitions.track` built from them (`width 320ms` on `easings.standard`, the utility `transition-track`, which `Track` alone applies and only under `motion-safe:`). Two values stay for their screens until their restyle: `min-h-plot` (96 px, the `PlotTile`) and `w-numeral` (74 px, the `NumberField`). The breakpoints (`md` 48rem, `lg` 64rem, under the theme's `extend`; `useMapColumns` reads `lg`) and the scroll margin (`scroll-mt-status`, `calc(var(--status-block-height) + 1px)`, the property `statusBlockHeightProperty` names, #506) are layout constants. `src/design/tokens.test.ts` declares ADR 043's 28 pairs in both themes, each `text` at 4.5:1 and `boundary` at 3:1 (WCAG 2.2 AA, N8), and its four exemptions, three under WCAG 1.4.11 (`line` on a surface, a block on `surface`, a silhouette on `surface`) and one under 1.4.3 (the disabled `line-strong` label on `surface-sunken`); an exempt pair fails once it passes on its own. A new color pair is declared there. Hex colors live here and, as SVG fixtures, in the tests under `src/art/`.
- `src/design/tailwindTheme.ts` — the Tailwind plugin built from `tokens.ts`: the `--<token>` color variables per scheme, the theme (`h-track` under its `extend`), one `.transition-<token>` utility per transition token (ADR 009, ADR 029), and one `.text-<style>` utility for what a font-size tuple cannot hold: `word`'s size from `md`, `meta`'s uppercase and `numeral`'s tabular figures. No color is named like a type style, so `text-gloss` sets the type style. `src/styles.css` loads it with `@plugin`.
- `src/design-system/` — the hand-drawn SVG icons and the visual primitives (resource bar, building card, art card, countdown, build slot, panel, track), and `buildingArtOf`, the only file that knows the path of a building image under `public/art/buildings/` (tier = ceil(level / 2), none at level 0; the file-existence test covers every building from level 1 to 10), and `campThumbnailOf`, the only file that knows the path of a bandit camp's 96 px image, `/art/camps/camp-<tier>-96.webp` (`cwebp -q 78 -m 6 -resize 96 0`, #557; its test checks every tier's file exists). `placeArtOf(place, level)` is the only file that knows a town place's image: it inlines `public/art/places/<place>.svg` through a `?raw` import and answers the shapes to draw, the silhouette in `surface-sunken` at level 0, and from level 1 the file's own hue with the first `level` windows; `placeSilhouetteOf(place, token)` answers the silhouette alone in a token. `PlaceArt` draws those shapes in a `size-place-card` square, the `0 0 100 142` frame letterboxed inside it; only Android sizes its width from the frame. `blockHueOf(index)` answers the hue of an index, and `hueClassOf(hue)` its class. `CardArt` holds the medieval `<img>`, the 4:3 cover image, and only the fief uses it; `BuildingCard` takes its picture as `art`, a node. `resourceAccent` keys the medieval resources, the town's (`money`, `food`, `power`, `material`, with `MoneyIcon`, `PowerIcon` and `MaterialIcon`), `peasants` and `people` (`PeopleIcon`). ## Gotchas

- No raw `fetch` with an ad-hoc shape. A call to the api is typed by a schema from `@mygame/contracts`.
- The design system is the only source of visual primitives: style with the Tailwind utilities the theme derives from `tokens.ts` (`bg-surface`, `p-4`, `text-body`), never a hex, a px literal or a `style` prop. Arbitrary values (`p-[13px]`) fail `biome check`. A missing value goes into `tokens.ts`. Check: `rg -n "#[0-9a-fA-F]{6}" apps/web/src --glob '!**/tokens*' --glob '!**/art/**'` stays empty.
- No Spanish outside the catalog (`packages/catalog/es.json`); identifiers stay English.
- The catalog holds `refusal.TokenInvalid` and `refusal.MailNotSent`; `knownPlayer` in `stubApiClient.testSupport.ts` carries `emailVerified: true`.
- `knownFief` carries `combatTerms` and `unitTerms` as the shipped content gives them, and every march fixture carries `order: 'forage'`, `camp: null` and `fought: false`. An attack fixture carries `order: 'attack'`, `stayHours: 0`, `arrivesAt` equal to `leavesAt`, a `camp` and `fought`; the attack card tests are in `src/fief/fiefAttackRoute.test.tsx`.
- React 19 holds a commit until every head stylesheet fires `load`, which jsdom never does, so the root document rendered empty in tests. `vitest.setup.ts` dispatches `load` on each stylesheet or style preload link as it is inserted.
- No snapshot tests. Components are tested through Testing Library queries by role and text; visual verification is a screenshot in the PR.
- `renderAppAt(path, client, { isStrict: true })` renders under `StrictMode`, the only way a test sees an effect run twice; use it for a post-once test. A double-click test fires both clicks in one `act` with a held promise; two separate clicks let React disable the button in between and never reach the in-flight guard.
- `formatQuantity` groups thousands with a narrow no-break space (U+202F), so a figure never wraps; Testing Library's default normalizer turns it into a plain space, so a `getByText` expectation writes `1 200` with a plain space, while a `textContent` or array expectation writes `1\u202f200`.
- The api tests truncate the database that `DATABASE_URL` points at, so run `pnpm gate` before seeding a visual check, never between seeding and the screenshots.
- Tailwind's default colours and spacing multiplier are replaced by the tokens, so `bg-red-500` or `p-7` emit nothing; breakpoints stay Tailwind's defaults.
- `src/design/tailwindTheme.ts` has a default export, the single exception to "named exports only": Tailwind's `@plugin` reads `module.default ?? module` and needs the plugin object there (ADR 009).
- `tailwindcss()` is the first Vite plugin, before `tanstackStart()`.
- Tailwind's source detection skips what the root `.gitignore` names. Without it the server build scans the client files the client build just wrote, emits a stylesheet with another hash, and the SSR head links a `/assets/styles-*.css` that answers 404. `.output/` and `.vercel/` are in `.gitignore` for that reason.
- pnpm refuses packages younger than its minimum release age. Pin the newest version old enough instead of adding a `minimumReleaseAgeExclude` entry.
- `refusal.PlotReserved` reads *Esa parcela está reservada: un colono va de camino a fundar en ella. Elige otra.*
- `neutralPercent` (`src/seasons/neutralPercent.ts`) is the one 100 a season percent is compared or scaled against; no `=== 100` on a percent.
- A founding fixture carries `order: 'found'`, a `name`, one settler, `stayHours: 0`, `arrivesAt` equal to `leavesAt`, `returnsAt` one more way after, `camp: null` and `fought: false`; a recalled one carries `arrivesAt` and `leavesAt` at `recalledAt` and `returnsAt` as long after as the settler walked, as the domain's `marchInstantsOf` answers.
