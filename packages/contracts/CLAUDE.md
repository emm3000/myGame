# packages/contracts

The wire vocabulary `apps/web` and `apps/api` share: zod schemas and the types inferred from them.

## Commands

- `pnpm --filter @mygame/contracts test` — Vitest, `src/**/*.test.ts`.
- `pnpm --filter @mygame/contracts typecheck` — `tsc --noEmit` against `tsconfig.base.json`.

## Gotchas

- Schemas only. No exported function, no behavior: `rg -n "^export (async )?function" packages/contracts/src` stays empty.
- One entry file: `src/index.ts` is the root export and the only one (`exports["."]`); the town's schemas live at `src/` root beside the others. Consumers import `@mygame/contracts`, never a path under `src/`.
- A schema is named `<wire noun>Schema` (`HealthResponseSchema`); its type is the same noun without the suffix, inferred with `z.infer` (`HealthResponse`). Never hand-write a type that duplicates a schema.
- No dependency on the domain package until a slice needs a domain type on the wire; that slice adds it.
- `zod`, `typescript` and `vitest` versions live in the root catalog; write `catalog:` here, never a version.
- One schema per file under `src/`, named after its wire noun (`TownOverview.ts`); `src/index.ts` only re-exports. Shared primitives (instants, whole-second durations, counts) live in `src/Wire.ts` and are not exported from the entry.
- The OpenAPI document the api emits is generated from these schemas (`@hono/zod-openapi` over `@asteasolutions/zod-to-openapi`), and the native clients are generated from that document with no rewrite (#590). A whole number is `z.number().int()` (or a `Wire.ts` primitive built on it), never `z.literal(0)`: a number literal is written `type: number`, and `z.literal([1, 2, 3])` is written with its first value alone. A fixed zero is `WholeCountSchema.max(0)`; a closed set of whole numbers is a numeric `z.enum`. Each union and each of its members carries `.meta({ id })` (`NextStep` and its four steps, `Goal`, `PendingGoal` and `UnderwayGoal`, `DueReview`, `RecognitionReview`, `RecallReview`, `ReviewVerdict`, `NearMissVerdict`, `CorrectVerdict`, `WrongVerdict`, `TownNewsItem` and each of its members, `ApiError` and each of its members), since the generator writes a `discriminator` only when every member is a named component. A nullable union is `z.lazy(() => Union).nullable()`: a plain `Union.nullable()` names the nullable copy as the component and drops its discriminator, while the lazy one answers `allOf: [{ $ref }, { nullable: true }]` beside the clean component. A `z.record` over an enum needs every key at parse, but the generator writes it as an object of optional properties, so each one carries `.meta({ required: <KeySchema>.options })` (`TownOverview.stocks` and `buildings`); the meta changes the document only, never the parse (#633). `apps/api/src/openApi.test.ts` fails on a number literal, a union without its discriminator, a nullable union that lost either, or an object of the committed document with a property missing from its `required`.
- Instants are ISO 8601 strings (`z.iso.datetime()`), durations are whole seconds; no `Date` crosses the wire.
- Wire identifiers are camelCase (`powerStation`); the Postgres enum spells it `power_station`, so the api adapter maps between them.
- `PlayerSchema` is a strict `{ id, email, emailVerified }`. `VerifyEmailRequest.ts` holds `VerifyEmailRequestSchema`, a strict `{ token }` with a non-empty string. `ApiErrorKind` includes `TokenInvalid` and `MailNotSent`. It includes `MalformedEmail` (#604), the sign-up email that fails `z.email()`. `SignUpRequestSchema` is a strict `{ email, password }`, the password at least 8 characters.
- `ForgotPasswordRequest.ts` holds `ForgotPasswordRequestSchema`, a strict `{ email }`. `ResetPasswordRequest.ts` holds `ResetPasswordRequestSchema`, a strict `{ token, password }` with a non-empty token and the 8-character password rule of sign-up.
- Lesson 1 over the wire (#713, ADR 036). `LessonContent.ts` holds `LessonContentSchema`, the api's lesson file: a strict `{ id, theme, durationSeconds, requiredSchoolLevel, wordIds }`, `wordIds` at least one, with no `skill` (ADR 039, #738). `LexiconContent.ts` holds `LexiconContentSchema`, `words.json`: at least one strict `{ id, lemma, partOfSpeech, frame, gappedFrame, gloss, definition?, acceptedForms?, homographs?, isOffList? }`, `partOfSpeech` `noun`, `verb`, `adjective` or `adverb`, `gloss` a strict `{ es? }` (a word no lesson teaches yet may lack it; the content gate requires it of a taught word), `homographs` a record from a frame's form to the headword it means, `isOffList` only `true`; no rank. `CurriculumContent.ts` holds `CurriculumContentSchema`, a strict `{ chromeLessonCount, lessonIds, skill }`, `lessonIds` at least one, `skill` a strict `{ cycle, ratePercent }`, `cycle` at least one of the town's `ResourceKind` (#769). `GrammarContent.ts` holds `GrammarContentSchema`, a strict `{ structures }`, at least one strict `{ name, cefr, cefrjItem, admittingLessonId, frameWords, inflections }`, `cefr` a CEFR-J level from `A1.1` to `B2.2`, `frameWords` and `inflections` possibly empty (#740). `StartLessonRequestSchema` is a strict `{ lessonId }`, non-empty; `StopLessonRequestSchema` and `ReviewRequestSchema` parse the paths `{ lessonId }` and `{ wordId }`; `ReviewAnswerRequestSchema` is a strict `{ answer }`, at most 100 characters, empty allowed (graded wrong). `ReviewHintSchema` is a strict `{ words }`, at least one `ReviewHintWord` (its own component, not exported from the entry), a strict `{ firstLetter, letterCount }` per word of the unit, in order (ADR 044). The learning wire is the player's, each schema in its own file at the root entry: `ReviewVerdict.ts` holds `ReviewVerdictSchema`, a union on `kind` (`NearMissVerdict` `{ kind: 'nearMiss' }`, `WrongVerdict` `{ kind: 'wrong', word, gloss, dueAt }`, `CorrectVerdict` `{ kind: 'correct', word, gloss, dueAt, earnedSkill }`), `earnedSkill` `null` or an `EarnedSkill` (`EarnedSkill.ts`, not exported from the entry: a strict `{ lessonId, resource, ratePercent, earnedAt }`, `resource` the town's `ResourceKind`) with `level` (a whole count from 1, the skill's level after the earn, #732), `ratePerHourBefore` and `ratePerHourAfter`, each `null` when the player holds no town, exported as the `RaisedSkill` type. `ReviewAnswerSchema` is a strict `{ verdict }` (`ReviewAnswer`). `DueReview.ts` holds `DueReviewSchema` (`DueReview`), a union on `mode`: a recognition (`RecognitionReview`) `{ wordId, lessonId, dueAt, mode, word, frame, choices }` (`choices` strict `{ choiceId, gloss }`, never a word id, which the card's own `wordId` would match; the ids are opaque and deterministic, not secret, ADR 036 rule 3), a recall (`RecallReview`) `{ wordId, lessonId, dueAt, mode, gloss, gappedFrame }`, which holds no lemma. `Reviews.ts` holds `ReviewsSchema` (`Reviews`), a strict `{ due, nextDueAt }`. `LessonState.ts` holds `LessonStateSchema`, a strict `{ id, theme, durationSeconds, requiredSchoolLevel, skill, isStudied, words }`, `skill` on the town's `ResourceKind`, each word a strict `{ wordId, standing, reading }`, `standing` `notStarted`, `recognize`, `recall`, `hold` or `retained`, `reading` a strict `{ word, gloss, frame }` or `null`, `null` once the card has a review, and for a held-out word or a word with no card outside its running lesson; `TownOverview` carries it. `ApiErrorKind` gains `LessonSchoolTooLow`, `LearningCapReached`, `LessonAlreadyStudied`, `LessonUnderStudy`, `LessonStudyNotFound`, `ReviewNotDue`, `HintOnRecognition`, `UnknownChoice`, `WordNotHeld` and `UnknownWord`.
- `ApiErrorSchema` (ADR 038, #736) is a discriminated union on `kind` of strict objects, with no `message`: `BareApiError`, `{ kind }` for every `ApiErrorKind` with no fields, and one member per kind with fields, each `{ kind, params }`:. The town's kinds (#765) are in the town's words: `TownNotFound`, `PlayerAlreadyHoldsTown` and `BlankTownName` bare, and `WaitingListFullError` (`{ cap }`), `NotEnoughPeopleError` (`{ requiredPeople, freePeople }`), `NotEnoughResourcesError` (`{ missing }`, a town `ResourceAmounts`), `TopLevelReachedError` (`{ building, level }`, a town `BuildingKind`) and `BuildingWorkNotFoundError` (`{ building, level }`, the level from 1), and the school's `LearningCapReachedError` (`{ learningCap, cardsInLearning }`, the cap from 1, #770). The union carries `.meta({ id: 'ApiError' })` and each member its own id, so the document writes the discriminator, every `BareApiError` kind mapped to that one component, and the Kotlin client generates one wrapper per kind. A kind with fields without its `params`, `params` on a kind without fields, or a `message` fails the parse.
- The town's content schemas (#759): `ResourceKindSchema` (`money`, `food`, `power`, `material`), `ResourceAmountsSchema` (strict, whole from 0), `BuildingKindSchema` (the seven buildings), `HireKindSchema` (`worker`, `truck`), `BuildingContentSchema` (strict, a union on `building`, each level `{ level, cost, durationSeconds, people, effect }`) and `TownContentSchema` (strict settings, `seasons.productionPercent` a record over `SeasonKind`, `fall` included, of a whole percent from 1 per resource). Beside them the town's wire (#765, absorbing #761): `TerrainSchema` (`fields`, `river`, `hills`); `FoundTownSchema` (`FoundTown`), a strict `{ name }` trimmed before `min(1)`, so a blank name fails on `name` as `too_small`; `StartBuildingWorkSchema` (`StartBuildingWork`), a strict `{ building }`; `StopBuildingWorkSchema`, the path `{ building, level }`, `level` a whole count from 1 written in the path; `BuildingWorkSchema` (`BuildingWork`), a strict `{ building, level, cost, startsAt, finishesAt }`; and `TownOverviewSchema` (`TownOverview`), a strict `{ name, label, site, terrain, season, stocks, people, buildings, work, readAt }`: `label` `town` or `city`, `site` a strict `{ region, area, site }`, `season` `null` before the epoch or a strict `{ kind, year, endsAt }`, `stocks` a record over the town's `ResourceKind` of a strict `{ amount, ratePerHour, capacity }`, `people` a strict `{ supplied, free, atWork }`, `buildings` a record over the town's `BuildingKind` of `{ level, nextLevel }`, `nextLevel` `null` at the top or a strict `{ level, cost, durationSeconds, people }`, `people` the occupancy the level adds, and `work` a strict `{ slot, waitingList, cap }`, `slot` `z.lazy(() => BuildingWorkSchema).nullable()` and `waitingList` an array of `BuildingWork` in order. Since #769 it also carries `lessons` (an array of `LessonState`), `skills` (an array of `EarnedSkill`, the player's) and `lessonSlot`, `null` or a strict `{ lessonId, startedAt, finishesAt }`, the school's running lesson, and `learning`, a strict `{ cap, inLearning }` of whole counts, the cap from 1 (#770); `TownContentSchema`'s `seasons.durationPercent` is a strict `{ build, study }` per season. Since #789 `TownContentSchema` also carries `goals`, an ordered array of strict `{ building, level }`, a town `BuildingKind` and a level from 1, buildings only (ADR 042), and `tips`, an ordered array of `TipKind` (`TipKind.ts`, `people`, `seasons`, `waitingList`, `office`, `jobs` or `fullStore`) that refuses a tip listed twice. Since #837 it also carries `nextStep`, a `NextStep` (`NextStep.ts`, a union on `kind`, each member its own id: `ReviewsStep` `{ kind, count, readFirst }`, `count` from 1, `LessonRunningStep` `{ kind, producer }`, `producer` `farm`, `factory`, `powerStation` or `null`, `LessonToStudyStep` `{ kind, lessonId }`, `CaughtUpStep` `{ kind, goal }`), and `nextDueAt`, the next review's instant or `null`. Since #790 (ADR 042) `CaughtUpStep.goal` is `z.lazy(() => GoalSchema).nullable()`, `null` once the guidance is dismissed or no goal is left: `Goal.ts` holds `GoalSchema` (not exported from the entry), a union on `state`, each member its own id, `PendingGoal` `{ position, count, building, level, state, missing }`, `missing` a strict `{ resources, people }`, `resources` a town `ResourceAmounts`, and `UnderwayGoal` the same placement with no `missing`; `position`, `count` and `level` from 1. No other step carries a goal, so no client can draw one beside another next step. `TownOverview.tip` is the `TipKind` to show or `null`. `MarkTipSeen.ts` holds `MarkTipSeenSchema`, the path `{ tip }`, a `TipKind`. `TownOverview.learning` carries `retainedWords`, a nullable strict `{ count, total }`, both whole, `total` from 1: the words at `retained` in the first lesson with no earned skill, among the words the player holds. It is null when no lesson has an unearned skill or the player holds none of that lesson's words (ADR 043, #871). No client computes it (N1).
- Town News and the Report (#772, ADR 040, ADR 038): `TownNewsItem.ts` holds `TownNewsItemSchema` (`TownNewsItem`), a union on `kind` of strict `{ kind, params, occurredAt }`, no prose, one member per `TownEvent` kind, each its own id (`BuildingWorkFinishedNews` `{ building, level }`, `BuildingWorkStoppedNews` `{ building, level, refund }`, `LessonStudiedNews` and `LessonStoppedNews` `{ lessonId }`, `SkillEarnedNews` `{ lessonId, resource, ratePercent }`, `HiringDeliveredNews` `{ hire, count }`, `HiringStoppedNews` `{ hire, delivered, stopped, refund }`, `JobBackNews` and `JobCalledBackNews` `{ site, pay }`, `CleanUpDoneNews` `{ site, reward }`, `CleanUpFailedNews` `{ site }`), and `BecameCityNews` `{ kind, occurredAt }` with no `params`, as `BareApiError` carries none. `TownNewsFeedSchema` (`TownNewsFeed`) is a strict `{ items }`, at most 100. `ReportSchema` (`Report`) is a strict `{ dueCount, due, readFirst, nextDueAt, news }`: `due` an array of `DueReview`, `readFirst` the ids of the lessons holding a due card with no review, in curriculum order, `nextDueAt` the next review's instant or `null`, `news` at most 100 `TownNewsItem`. `SiteAddress.ts` holds the strict `{ region, area, site }` that `TownOverview.site`, `TownOverview.job` and the news share, not exported from the entry.
- The region map and the jobs (#782, ADR 014, ADR 019, ADR 040): `RegionMapSchema` (`RegionMap`), a strict `{ region, area, lastArea, terrain, sites }`, each site a strict `{ site, town, waste }`, `town` `null` when free or a strict `{ name, isOwn }`, never the holder's id, `waste` `null` or a strict `{ size, waste }`, `size` a `WasteSize` (`WasteSize.ts`, the numeric `z.enum` 1, 2 or 3, not exported from the entry) and `waste` whole from 0 (#786); `RegionMapRequestSchema`, the path `{ area }`, a whole count from 1 written in the path. `SendJobSchema` (`SendJob`), a strict `{ site, team, hours }`, `site` a strict `{ area, site }` from 1, `team` a `Team` (`Team.ts`, a strict `{ worker, truck }` of whole counts, not exported from the entry), `hours` from 1; `CallJobBackSchema`, the path `{ sentAt }`, an instant. `SendCleanUpSchema` (`SendCleanUp`, #786), a strict `{ site, team }`, no hours. `Team` carries `.meta({ id: 'Team' })`. `TownOverview.job` is `null` or a `TownJob` (`TownJob.ts`, not exported from the entry, #786), a union on `kind`, each member its own id and `phase` the named `JobPhase`: `Job` `{ kind: 'job', site, team, pay, phase, sentAt, arrivesAt, leavesAt, returnsAt, calledBackAt, hours }`, `hours` from 1, and `CleanUpJob` `{ kind: 'cleanUp', …the same fields…, size, waste }` with no hours, `leavesAt` its arrival; `pay` a town `ResourceAmounts`, `phase` `outbound`, `working` or `returning`, `calledBackAt` `null` until a call back. `JobQuoteSchema` (`JobQuote`, #958) is a strict `{ pay }`, a town `ResourceAmounts`: the pay a `SendJob` would fix if sent at the quote's instant, so no client computes it. `CleanUpQuoteSchema` (`CleanUpQuote`, #965) is a strict `{ strength, waste, pay, covers }`, `strength` and `waste` whole from 1, `pay` a town `ResourceAmounts`, `covers` whether the strength covers the waste (#979): what a `SendCleanUp` would fix at the quote's instant, none when the strength falls short of the waste. `ResourceAmounts` and `WasteSize` carry `.meta({ id })`, so the document names each one component and the Kotlin client one class. `ApiErrorKind` gains `AreaNotFound`, `InvalidTeam`, `JobSiteOutOfBounds`, `TeamAlreadyOut`, `JobToOwnSite`, `SiteHeld`, `JobNotFound` and `JobAlreadyReturning`, bare, and `JobHoursOutOfRangeError` (`{ hours, maxHours }`, both from 1) and `NotEnoughHiresAtHomeError` (`{ hire, count, atHome }`); #786 adds `NotAWasteSite` and `NoWasteYet`, bare.
- Placement (#743, ADR 037): `Placement.ts` holds `PlacementSchema` (`Placement`), a union on `kind`, each member its own id: `OfferedPlacement` `{ kind }`, `AskingPlacement` `{ kind, band, items, scores }`, `items` 1 to 30 `PlacementItem` `{ wordId, word, choices }`, `choices` 1 to 4 strict `{ choiceId, gloss }`, and `ClosedPlacement` `{ kind, scores }`; each `PlacementScore` is `{ band, score, takenAt, isPlacedOut }`, `score` whole from 0 to 30 and `isPlacedOut` the api's answer, so no client applies the 29 of 30 cut. `PlacementAnswers.ts` holds `PlacementAnswersSchema` (`PlacementAnswers`), a strict `{ band, answers }`, 1 to 30 strict `{ wordId, choiceId }`. `PlacementBand.ts` holds `PlacementBandSchema` (`PlacementBand`), the numeric `z.enum` 1, 2 or 3 with its id. The placement's refusals are not `ApiErrorKind` members: the api answers them with an empty body.
