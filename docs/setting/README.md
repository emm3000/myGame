# Setting

Townword's world: a present-day town the player grows into a city (ADR 035). This directory replaces `docs/lore/`, written new and not adapted from it (`docs/research/english-pivot/decisions.md` §10.2).

## Structure

```
docs/setting/
  README.md      this file
  lessons.md     the lessons: their themes and items, each word with its NGSL 1.2 rank
```

The town, the region and the people in the news land here with the town rebuild. Until a page lands here, `docs/lore/` names what the shipped medieval game shows, and the Spanish chrome around the first lesson stays in `docs/lore/names.md`, The review.

## Rules

- Every name and every word a player reads is an NGSL 1.2 word where one exists, with its rank recorded beside it (ADR 035). *Mayor*, *storage* and *truck* are the accepted game nouns outside the first bands, taught and never counted toward progress.
- American English; the season is *fall*.
- No real places, brands, politics or people, and no magic.
- A scaffold gloss in Spanish addresses the reader as tú, never vos.

## Authorship

The author writes or approves every page. A Claude session may draft one when a ticket asks for it and marks every invented fact as a proposal until the author accepts it.
